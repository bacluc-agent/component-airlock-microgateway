= Parameters

The parent key for all of the following parameters is `airlock_microgateway`.

Api reference for Gateway API can be found here: https://gateway-api.sigs.k8s.io/reference/spec

Api reference for Airlock Microgateway CRs can be found here: https://docs.airlock.com/

== `namespace`

[horizontal]
type:: string
default:: `syn-airlock-microgateway`

The namespace in which to deploy this component.

== Example

[source,yaml]
----
namespace: example-namespace
----

== `gatewayparameters.spec.features.externalNameServicesAllowed`

[horizontal]
type:: boolean
default:: `false`

Note that this is only available from v5.0.0 see https://github.com/airlock/microgateway/releases/tag/5.0.0 and configurable since v4.8.6.

== Example

To set it on a specific instance.
[source,yaml]
----
instances:
  vshn-default-test-01:
    gatewayParameters:
      spec:
        features:
		  externalNameServicesAllowed: true
----

To set it on all instanes of an environment.
[source,yaml]
----
default:
  gatewayParameters:
    spec:
      features:
        externalNameServicesAllowed: true
----

== `default.gatewayParameters.defaults.customResponses`

Allows to set the local and upstream customResponses, see
https://docs.airlock.com/microgateway/5.0/index/api/crds/gateway-parameters/v1alpha1/index.html#gatewayparametersspecdefaultscustomresponses[Airlock Microgateway docs].

The first matching entry is used.
It is not possible to override an existing range of the defaults in an instance because the additional customResponse configurations are appended because it is an array.

For placeHolders see https://www.envoyproxy.io/docs/envoy/latest/configuration/advanced/substitution_formatter#config-advanced-substitution-operators[envoy substitution operators].

== Example

[source,yaml]
----
default:
  gatewayParameters:
    defaults:
      customResponses:
        local:
          - statusCodeCondition:
              matcher:
                exact: 401
            customResponseRef:
              name: "401"
          - statusCodeCondition:
              matcher:
                range:
                  from: 400
                  to: 499
            customResponseRef:
              name: "4xx"
  customResponses:
        "401":
          content:
            - contentType: text/html
              body:
                value: |
                  <!DOCTYPE html>
                  <html lang="de">
                  <head>
                      <meta charset="utf-8">
                      <meta name="viewport" content="width=device-width, initial-scale=1.0">
                      <title>Customer Error 401</title>
                      <style>
                          @media (max-height: 550px) {
                              body { overflow-y: auto; height: auto; }
                          }
                      </style>
                  </head>
                  <body>
                  <main>
                      <h1><span class="textcode">Error </span>401</h1>
                      <section>
                        <h2 lang="de">Access Denied</h2>
                        <p lang="de">You can't access this application.<br>
                        Additional info: <a href="https://support.customer.com">Support</a>.</p>
                      </section>
                  </main>
                  <footer>
                      REQUEST ID: %STREAM_ID%
                  </footer>
                  </body>
                  </html>
              headers: {}
        "4xx":
          content:
            - contentType: text/html
              body:
                value: |
                  %RESPONSE_CODE%
----

== `default.redisSecretSync`

Copies redis connection secrets from a source namespace into the airlock-microgateway instance namespace with an espejote `ManagedResource`.
The `ManagedResource` only manages secrets in the instance namespace.
The feature is disabled by default and can be enabled for all instances through `default` or for individual instances.

[horizontal]
type:: object
default:: `enabled: false`, `sourceNamespace: vshn-airlock-redis`, `secrets: {redis: redis-creds-connection}`

`enabled`:: Whether the `ManagedResource` is generated for the instance.

`sourceNamespace`:: The namespace that contains the source secrets.

`secrets`:: A map from a target prefix to the name of one source secret in `sourceNamespace`.
Each entry creates three secrets in the instance namespace: `<prefix>-password` with `redis.password` from `REDIS_PASSWORD`, `<prefix>-ca` with `ca.crt` from `ca.crt`, and `<prefix>-clientcert` of type `kubernetes.io/tls` with `tls.crt` and `tls.key` from the same keys.
The source secret must contain all four keys.
Set a prefix to `null` to remove that set, or set `secrets: null` to remove all sets.
An empty map leaves the defaults unchanged.
If no sets remain, no `ManagedResource` or RBAC resources are generated.
The `ManagedResource` aborts reconciliation if a source secret does not exist, is being deleted, or lacks a required key.
The default creates `redis-password`, `redis-ca` and `redis-clientcert` from `redis-creds-connection`.
Add another prefix to switch an instance to new redis secret names without downtime.

== Example

[source,yaml]
----
instances:
  vshn-default-test-01:
    redisSecretSync:
      enabled: true
      sourceNamespace: vshn-airlock-redis
      secrets:
        redis: redis-creds-connection
        redis-old: redis-creds-connection-old
        redis-unused: null
----
